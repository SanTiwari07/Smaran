## Bandwidth

- Smaran: 2,889,767 bytes · sync-everything: 4,675,998 bytes
- **Saved: 38.2%** (target >= 40%) · private notes kept on device: 107
- Savings come only from what is *not* sent. Each op is ~9 KB because the 384-d dense vector travels as JSON text; sending float16 binary (or letting the server re-embed) would cut every op by ~5x.
